GUIDE DE DÉPLOIEMENT — ExamTech Cameroun

Ton app vit pour l'instant en aperçu. Pour avoir une vraie adresse (ex : examtech-cameroun.vercel.app) que tu peux ouvrir sur ton téléphone et partager, il faut 2 étapes : (1) mettre le code sur GitHub, (2) brancher Vercel. C'est gratuit, sans carte bancaire.

CHECKLIST — Déploiement : 1 / 5
[x] J'ai un compte GitHub
[ ] J'ai téléchargé le pack
[ ] J'ai mis le pack sur GitHub
[ ] J'ai branché Vercel
[ ] J'ai ouvert mon adresse et testé le login démo

ÉTAPE 1 — Compte GitHub
Va sur github.com/signup (gratuit) et crée ton compte. Note ton nom GitHub : il servira pour l'adresse de ton dépôt.

ÉTAPE 2 — Télécharger le pack
Dans l'app, clique sur « Télécharger le pack ExamTech (HTML) ». Tu reçois le fichier examtech-cameroun.html.
Note : dans la version déployée, tes données sont enregistrées dans la base de données de l'application, pas dans ce fichier.

ÉTAPE 3 — GitHub
Sur GitHub : « Nouveau dépôt » → nom examtech-cameroun → Public → Add README → Upload files → glisser examtech-cameroun.html → Commit.
Ou avec git (remplace TON-NOM par ton nom GitHub) :
git init
git add .
git commit -m "ExamTech Cameroun"
git branch -M main
git remote add origin https://github.com/TON-NOM/examtech-cameroun.git
git push -u origin main

ÉTAPE 4 — Vercel
Va sur vercel.com/signup → Add New → Project → Import Git Repository → choisir examtech-cameroun → Deploy.
Aucune commande de build n'est nécessaire (HTML statique). Framework : Other, Build Command : laisser vide.
Après Deploy, Vercel te donne ton adresse : https://examtech-cameroun.vercel.app

ÉTAPE 5 — Tester en ligne
Ouvrir l'adresse sur téléphone → Tester compte démo demo@examtech.cm / demo1234 → Générer une épreuve → Exporter PDF.

DÉPANNAGE
- Mon adresse affiche une page blanche : attends 1 minute, puis vide le cache de ton navigateur et rouvre l'adresse.
- Vercel demande un Build Command : laisse-le vide, et choisis Framework : Other.
- Mon dépôt n'apparaît pas : vérifie que tu es connecté au bon compte GitHub, puis actualise la page Vercel.
- Je n'ai pas d'ordinateur : tout se fait depuis le téléphone, GitHub et Vercel ont des sites mobiles.
